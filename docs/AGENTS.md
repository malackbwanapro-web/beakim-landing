## 3. Maintenance & Formatting Rules
1. **GitHub Flavored Markdown:** Maintain clean markdown tables, callout alerts (`> [!NOTE]`, `> [!TIP]`, `> [!IMPORTANT]`), and visual ascii/mermaid diagrams for executive readability.
2. **Deterministic Evidence:** Every keyword cluster must link to verified on-page code artifacts (`<title>`, `<meta description>`, `<h1>`, image `alt`, JSON-LD schemas).
3. **Frictionless Verification:** Provide direct 1-click test links (e.g. Google Rich Results Test) and clear Search Console inspection workflows.
4. **Parent Bubble-Up:** Any addition or deletion of files within `docs/` must be recorded in this `AGENTS.md` and indexed in the root [`../AGENTS.md`](../AGENTS.md).
