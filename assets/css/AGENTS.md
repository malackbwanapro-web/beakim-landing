# Beakim Landing - Stylesheets Domain (`assets/css/`)

## 1. Purpose & Ownership
- **Scope:** Public marketing landing page CSS stylesheets, typography definitions, color tokens, and custom animation utilities.
- **Key Entry Points:**
  - `input.css`: Source Tailwind CSS declarations and luxury custom base/utility rules.
  - `styles.css`: Compiled, minified production CSS bundle generated by Tailwind CLI.
- **Boundaries:**
  - Do NOT edit `styles.css` directly. Always make edits in `input.css` and recompile using `npm.cmd run build`.

---

## 2. Local Contracts & Rules
- **Color Palette:**
  - Champagne: `#C5A880` / `#B8965A` (Luxury gold accents)
  - Deep Forest: `#0D2318` / `#0B2518` (Primary dark background)
  - Canopy: `#133E2B` / `#1E4331` (Secondary elevated containers)
  - Ivory: `#FDFBF7` / `#F5F0E8` (Crisp reading text)
  - Driftwood: `#8C827A` (Muted secondary meta text)
- **Touch Ergonomics:**
  - `touch-action: manipulation;` enforced in `@layer base` for buttons, inputs, links, and cards to eliminate mobile double-tap delays.
- **Motion & Accessibility:**
  - `@media (prefers-reduced-motion: reduce)` must be declared on smooth-scrolling containers to support vestibular accessibility.

---

## 3. Work Guidance & Verification
- **Build Command:** `npm.cmd run build` (or `npm.cmd run build:css`)
- **Watch Command:** `npm.cmd run watch:css`
